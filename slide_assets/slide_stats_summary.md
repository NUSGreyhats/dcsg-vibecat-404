# DEFCON Dungeon — slide stats

Generated by `python3 tools/generate_slide_assets.py`.

## Copy/paste talking points

- **10 authored rooms** at **40×24 tiles** each (**9,600 map tiles** total).
- **120 possible enemy kills** if every reinforcement wave fires: **58 initial** enemies + **62 wave** enemies.
- **Room 10 is the spike:** 27 mobs, including the boss and a final 10-kamikaze wave.
- **5 enemy archetypes:** grunt, runner, tank, kamikaze, boss; late rooms scale HP ×1.6 and speed ×1.2.
- **3 weapons:** pistol, rifle, shotgun. The rifle has the highest theoretical server DPS at **26.7**.
- **17 authored health/ammo pickups**, plus **every kill drops a coin** for shop routing.
- **9 active intentional exploit mechanics** turn it from a dungeon crawler into a protocol speedrun puzzle.
- **Server rhythm:** 20 Hz ticks, 50 ms per tick, 100 HP player, 220 px/s base speed.
- **Leaderboard DB is currently empty** in this checkout, so the charts are build/design stats rather than player-performance stats.
