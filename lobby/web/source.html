The game's client and server source ship in a single tarball. Download, untar, and read with whatever editor you like — there's no formatting trickery.

Inside:

  • server/ — the Go game-server runtime
  • pkg/ — shared Go modules the server imports
  • client/ — the Phaser client (TypeScript)

Comments, tests, and build configs are stripped. The result still compiles cleanly.
